## 简介

本仓库用于沉淀个人在学习过程中整理的笔记，按方向分类归档。所有笔记默认采用「有基础速成」风格编写——假设读者已具备一定编程经验，重实战、轻铺垫，便于快速过完一遍知识后动手实践。

## 笔记风格

- **面向有基础的读者**：不重复讲「变量是什么」「for 循环怎么写」之类的入门内容
- **重实战**：每个方向至少配一个由浅入深的实战小项目
- **对比式讲解**：与其他语言的差异、坑点、注意点会高亮标出
- **示例驱动**：概念用最短的可运行示例串起来

## 如何使用

1. 按需选择对应方向的笔记阅读
2. 边看边动手敲一遍示例代码，加深印象
3. 跑通示例后再尝试笔记末尾的练习题或小项目
4. 嵌入式相关示例建议准备一块开发板（如 STM32）配合 STM32CubeIDE 或 VS Code + PlatformIO 使用
